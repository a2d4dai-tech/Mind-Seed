# Mind Seed を公開する手順

ここには、ログイン不要で誰でも使える Mind Seed のファイルが入っています。
下の手順どおりに進めれば、無料で公開できます。すべてブラウザの操作だけで、
プログラミングの知識は不要です。

作業は大きく2つです。

1. AI を動かすための「鍵」(APIキー)を発行する
2. このフォルダのファイルを Vercel という無料サービスに置いて、公開する

---

## 1. Anthropic の API キーを発行する

これは、あなたのMind SeedがClaudeに問いを考えてもらうための鍵です。

1. https://console.anthropic.com を開き、アカウントを作成(またはログイン)。
2. 左側メニューの **Billing**(お支払い)から、クレジットカードを登録する。
3. 同じ Billing のページで **使用量の上限(spend limit / budget)** を設定する。
   これがとても大事です。この上限を設定しておけば、リンクを誰にでも
   配っても、想定外に使われすぎて高額な請求が来る心配がありません。
   まずは月 5〜10ドルくらいから始めるのがおすすめです。
4. 左側メニューの **API Keys** から「Create Key」を押して、新しいキーを作る。
5. 表示された `sk-ant-...` から始まる文字列をコピーしておく(このあと使います)。
   このキーは誰にも見せないでください。

---

## 2. Vercel にアップロードして公開する

### 2-1. GitHubにこのフォルダを置く

1. https://github.com を開き、アカウントを作成(またはログイン)。
2. 右上の「+」から **New repository** を選び、名前を `mind-seed` などにして作成
   (Public でも Private でもどちらでも構いません)。
3. 作成したリポジトリの画面で **「uploading an existing file」** というリンクを押す。
4. このフォルダの中にあるファイル・フォルダ(`index.html`、`api` フォルダ、
   `package.json` など)をすべてドラッグ&ドロップでアップロードし、
   「Commit changes」を押す。
   (`.env.example` はアップロードしなくても構いません。`.gitignore` はアップロードして大丈夫です)

### 2-2. Vercelでデプロイする

1. https://vercel.com を開き、「Sign Up」から **GitHubでサインアップ** する
   (GitHubのボタンを押すのが一番簡単です)。
2. ダッシュボードで **「Add New...」→「Project」** を選ぶ。
3. さきほど作った `mind-seed` リポジトリを選んで **Import**。
4. 設定画面が出たら、**Environment Variables**(環境変数)という項目を探し、
   - Name: `ANTHROPIC_API_KEY`
   - Value: 手順1でコピーした `sk-ant-...` のキー
   を入力して追加する。
5. 他の設定はそのままで **Deploy** を押す。
6. 1分ほどで完了し、`https://mind-seed-xxxx.vercel.app` のようなURLが発行されます。
   これが、誰にでもログイン不要で配れるリンクです。

---

## 更新したいとき

コードを直したときは、GitHubのリポジトリのファイルを更新するだけで、
Vercelが自動的に再デプロイしてくれます。

## 心配なこと・確認したいこと

- リンクを配った後、想定より使われて費用が心配になったら、Anthropicの
  Billingページで使用量の上限をいつでも下げられます。上限に達すると、
  Mind Seed は静かに「うまくいきませんでした」というメッセージを出すだけで、
  それ以上の請求は発生しません。
- 個人の記録は、それぞれの人のブラウザの中(localStorage)にだけ保存されます。
  他の人の記録を見ることはできませんし、サーバーには保存されません。
