# Mind-Seed
SNSが普及し、幸せの物差しがだれかとの比較対象であることがスタンダードとなりつつある現代。
自分が今なにを考えているのか、なにに悩んでいるのか——気づけば、自分自身の思考すら
よく見えなくなっている人は少なくありません。

Mind Seed は、そうしてぐちゃぐちゃになった思考に、ただそっと寄り添うためのツールです。
答えを出したり、アドバイスをしたり、「こうすればいい」と導いたりはしません。
真っ黒な画面の中央に問いがひとつ浮かび、それに一言、二言で答えていく——それだけです。
AIは隣で静かに耳を傾け、あなたが今書いた言葉から、次に聞くべき問いをそのつど一つだけ考えます。
テンプレート的な聞き方はせず、あなた自身の言葉を踏まえた、その人だけの問いです。

書いてきた言葉は、右下の小さな白い丸からいつでも呼び出せます。
生の言葉がそのまま画面にふわりと浮かび上がり、もう一度押すとそれぞれの奥にある感情が
一語になって現れ、さらに押すとAIによる短い考察が、そっと差し出されます。

- **ログイン不要。** リンクを知っていれば誰でもすぐに使えます。
- **記録はその人のブラウザの中だけ。** サーバーには何も残らず、他人に見られることもありません。
- **終わりはこちらから決めません。** 会話は何回でも続けられ、Escキーでいつでも「今日はここまで」にできます。
